# Agents

## For future agent
This note points agents that read `AGENTS.md` (Codex, Cursor and others) to the files that govern this repository. Claude Code reads `CLAUDE.md` instead, which holds the same rules, so nothing here is new: it is a map, kept short on purpose.

## Where the rules are
- **Operating the brain** (writing notes, layers, skills): `CLAUDE.md`. Read it before writing anything in this folder.
- **Skills**: `.company-brain/skills/<name>/SKILL.md`; the catalog is `System/Skills.md`. In Claude Code they run as `/company-brain:<name>`; the project commands in `.claude/commands/company-brain/` are generated by `./brain commands`, so edit the skill, never the command.
- **Bringing in changes from obsidian-second-brain** (new commands, updated scripts and rules): `.company-brain/references/upstream-sync.md`. Start with `./brain upstream-check`.
- **The engine** (`.company-brain/`): change it only when asked to develop Company Brain itself. Files marked `"mode": "copy"` in `.company-brain/upstream.json` are vendored and must not be edited.
